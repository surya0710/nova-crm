# Dashboard User Guide

## Your workspace

The main dashboard shows widgets and quick actions tailored to your role, organization plan, and enabled modules.

## Quick actions

Shortcuts appear at the top of the dashboard for common tasks (create lead, apply leave, view tasks, etc.). Only actions you are permitted to use are shown.

## Widgets

The **Workspace Widgets** section lists active widgets. Widget data loads based on your permissions.

## Personal layout

If your administrator granted **Customize dashboard** permission:

1. Use dashboard API or future UI controls to rearrange widgets
2. Hide widgets you do not need
3. Click **Reset layout** to restore defaults

## Notifications & activity

Recent notifications and assigned work appear in the workspace payload via `/dashboard/workspace`.

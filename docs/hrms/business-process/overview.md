# HRMS Business Process Overview

## Overview
Defines key HR processes from onboarding to performance and payroll.

## Actors
- Employee
- Manager
- HR Administrator
- Payroll Officer

## Workflow Diagram
Employee Update -> Attendance/Leave -> Payroll -> Performance Cycle -> Review -> Feedback

## Detailed Steps
1. Maintain employee profile and assignments.
2. Capture attendance and process leave.
3. Run payroll and publish payslips.
4. Execute goals, reviews, and feedback cycles.

## Exceptions
- Attendance correction rejected
- Leave overlap or insufficient balance
- Payroll validation failures

## Related Modules
Workflow automation, metadata, compliance, and notifications.

## Best Practices
Use policy-driven approvals and timeline-based reminders.

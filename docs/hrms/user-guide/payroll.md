# HRMS User Guide - Payroll

## Purpose
Understand payroll run lifecycle and payslip availability.

## Who should use this feature
Payroll officers, finance partners, and HR administrators.

## Prerequisites
- Payroll period configured
- Salary structures assigned

## Step-by-step instructions
1. Open payroll period and verify employee coverage.
2. Run payroll validation and calculations.
3. Review exceptions and approvals.
4. Publish payroll and release payslips.

## Expected result
Payroll is processed accurately and on schedule.

## Best Practices
Resolve validation issues before approval and publishing.

## Common Mistakes
Publishing with unresolved warnings or missing assignments.

## FAQ
Document recalculation, reversals, and payment export issues.

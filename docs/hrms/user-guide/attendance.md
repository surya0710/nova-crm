# HRMS User Guide - Attendance

## Purpose
Track clock-in/clock-out and attendance corrections.

## Who should use this feature
Employees, managers, and HR attendance administrators.

## Prerequisites
- Attendance policy configured
- Shift assignment completed

## Step-by-step instructions
1. Record clock-in and clock-out events.
2. Submit correction when anomalies occur.
3. Review manager approval status.
4. Confirm attendance ledger is updated.

## Expected result
Attendance records are reliable for payroll and compliance.

## Best Practices
Clock in/out on time and submit corrections promptly.

## Common Mistakes
Missing punches and delayed correction requests.

## FAQ
Capture cut-off times, approvals, and exception handling.

# HRMS User Guide - Goals

## Purpose
Create and track goals aligned to performance objectives.

## Who should use this feature
Employees, managers, and performance program owners.

## Prerequisites
- Goal categories defined
- Review cycle and ownership rules configured

## Step-by-step instructions
1. Create goal with measurable target.
2. Assign owner and due timeline.
3. Post periodic progress updates.
4. Close goal as completed/cancelled with reason.

## Expected result
Goal progress is transparent and measurable.

## Best Practices
Use SMART goal definitions and regular check-ins.

## Common Mistakes
Vague targets and infrequent progress updates.

## FAQ
Document reassignment, cancellation, and weighting questions.

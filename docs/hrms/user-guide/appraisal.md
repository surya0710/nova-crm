# HRMS User Guide - Appraisal

## Purpose
Manage appraisal cycles and final evaluation outcomes.

## Who should use this feature
Employees, managers, calibrators, and HR administrators.

## Prerequisites
- Appraisal session created
- Reviewer assignments and calibration rules defined

## Step-by-step instructions
1. Start appraisal session for selected population.
2. Collect self and manager submissions.
3. Run calibration and finalize ratings.
4. Publish results and development actions.

## Expected result
Appraisal outcomes are fair, traceable, and actionable.

## Best Practices
Complete calibrations before final publication.

## Common Mistakes
Skipped calibration and missing evidence attachments.

## FAQ
Cover appeals, reopening, and timeline extensions.

# HRMS User Guide - Leave

## Purpose
Apply, approve, and track leave requests and balances.

## Who should use this feature
Employees, managers, and HR leave administrators.

## Prerequisites
- Leave policies and types configured
- Leave balance initialized

## Step-by-step instructions
1. Create leave request with dates and reason.
2. Submit request for manager approval.
3. Track approval/rejection status.
4. Review updated leave balance after decision.

## Expected result
Leave lifecycle is policy-compliant and fully traceable.

## Best Practices
Apply early and check overlaps before submission.

## Common Mistakes
Incorrect date ranges and missing request details.

## FAQ
Include cancellation, encashment, and carry-forward questions.

# HRMS User Guide - Performance

## Purpose
Manage performance cycles, goals, and evaluation activities.

## Who should use this feature
Employees, managers, and HR performance administrators.

## Prerequisites
- Performance cycle configured
- Templates and rating scales available

## Step-by-step instructions
1. Activate performance cycle.
2. Assign participants and timeline.
3. Complete self/manager assessments.
4. Finalize outcomes and development notes.

## Expected result
Performance evaluations are structured and consistent.

## Best Practices
Use objective evidence and timely check-ins.

## Common Mistakes
Late submissions and unclear rating justifications.

## FAQ
Include reopening rules, calibration, and score disputes.

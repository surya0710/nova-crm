# HRMS User Guide - Employees

## Purpose
Manage employee profiles and employment details.

## Who should use this feature
HR staff, managers, and authorized operations users.

## Prerequisites
- Employee management permissions
- Department and designation structures configured

## Step-by-step instructions
1. Create or open an employee profile.
2. Update required personal and job details.
3. Assign reporting manager and employment settings.
4. Save and verify profile completeness.

## Expected result
Employee data is accurate, searchable, and policy-compliant.

## Best Practices
Use validated data standards and periodic profile reviews.

## Common Mistakes
Incomplete records and outdated manager assignments.

## FAQ
Document profile updates, transfers, and access concerns.

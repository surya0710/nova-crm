# HRMS User Guide - Feedback

## Purpose
Collect structured feedback as part of development and appraisal.

## Who should use this feature
Employees, managers, reviewers, and HR facilitators.

## Prerequisites
- Feedback campaign or request configured
- Participants and timelines defined

## Step-by-step instructions
1. Launch feedback request or campaign.
2. Invite participants and monitor response status.
3. Submit feedback using defined criteria.
4. Review aggregated results and action points.

## Expected result
Feedback data supports growth and calibration discussions.

## Best Practices
Use clear prompts and response deadlines.

## Common Mistakes
Unclear question sets and low participant coverage.

## FAQ
Include anonymity, reopening, and response edits guidance.

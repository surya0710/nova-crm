# HRMS User Guide - Reviews

## Purpose
Run structured performance reviews and capture outcomes.

## Who should use this feature
Managers, reviewers, employees, and HR coordinators.

## Prerequisites
- Review assignments created
- Templates and rating criteria configured

## Step-by-step instructions
1. Open assigned review form.
2. Evaluate against criteria with evidence.
3. Submit review for workflow completion.
4. Confirm final score and comments.

## Expected result
Review outcomes are consistent and auditable.

## Best Practices
Ground ratings in documented performance evidence.

## Common Mistakes
Missing comments and inconsistent scoring rationale.

## FAQ
Cover reassignment, re-open, and moderation scenarios.

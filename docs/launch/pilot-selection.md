# Pilot Customer Selection

## Ideal pilot profile
- Willing champion and executive sponsor
- Scope ≤ 2–3 modules
- Able to go-live within 30–45 days
- Provides structured feedback weekly
- Not a custom-development dependent deal

## Selection checklist
- [ ] ICP fit confirmed
- [ ] Success metrics written
- [ ] Implementation capacity available
- [ ] Legal pilot terms signed
- [ ] CS + Impl owners assigned

## Cohort size
Recommend 3–5 pilots for launch wave; avoid over-concentration in one industry if seeking broad signal.

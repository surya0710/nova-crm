# Pilot Issue Tracking

Operational companion to the centralized [issue-register.md](./issue-register.md).

- All defects in support/engineering tracker with `pilot` label
- P1/P2 follow standard SLA
- Weekly triage: bug vs enhancement vs training gap
- Blockers to go-live escalated to Program Lead same day
- Mirror Issue ID (`ISSUE-P15.8-xxx`) in tracker title for traceability

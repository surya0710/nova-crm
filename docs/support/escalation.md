# Escalation Paths

| Level | Contact | Use when |
|-------|---------|----------|
| L1 Support | Support queue | Default |
| L2 Engineering | Eng on-duty | Confirmed defect / needs logs |
| On-call | Pager / phone | P1 / security |
| Product | Product manager | Feature / prioritization |
| CS Lead | Named CS | Churn risk / executive complaint |

Escalation packet: org, impact, timeline, steps, artifacts, customer sentiment.

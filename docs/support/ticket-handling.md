# Ticket Handling

1. **Triage** — priority, category, org ID
2. **Acknowledge** within SLA
3. **Reproduce** — least privilege; request screenshots/HAR as needed
4. **Resolve or escalate**
5. **Document** root fix / workaround
6. **Confirm** with customer → close

## Macros (suggested)
- Request repro steps
- Workaround provided
- Escalated to engineering (#ID)
- Resolved — please confirm

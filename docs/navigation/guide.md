# Navigation Guide

## Principles

1. **Modules** contain operational pages only.
2. **Organization Settings** contains configuration pages.
3. Sidebar length is intentionally reduced; deep recruitment/performance/payroll tools open from their module dashboards.

## Sidebar sections

- Main — Dashboard
- CRM — leads, customers, pipeline, products, quotations, invoices, payments, tasks, projects
- HR — dashboards, directory, employees, teams, announcements, exits, calendar, attendance, leave ops, recruitment entry, performance entry, payroll entry
- Self-Service — ESS pages
- Analytics — reports, finance, audit
- Settings — Organization Settings hub, integrations, workflows, metadata, access control, team, API tokens, knowledge, profile

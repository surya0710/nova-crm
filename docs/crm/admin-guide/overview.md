# CRM Administrator Guide

## Purpose
Define how CRM administrators configure and maintain secure day-to-day operations.

## Required configuration
- Pipeline stages and conversion rules
- Document numbering for quotations and invoices
- Tax and currency defaults

## Permissions
- `leads.*`
- `customers.*`
- `opportunities.*`
- `quotations.*`
- `invoices.*`
- `payments.*`

## Dependencies
- Organization profile and billing settings
- Team and role assignments
- Notification channels

## Configuration Steps
1. Configure master settings and numbering sequences.
2. Configure role-based access and approvals.
3. Configure follow-up reminders and outbound notifications.
4. Validate end-to-end sales to billing flow in a test cycle.

## Best Practices
Review role permissions quarterly and enforce standardized stage definitions.

## Troubleshooting
If users cannot perform an action, verify permission mapping, ownership rules, and workflow state.

# CRM Configuration Overview

## Purpose
Explains module-level CRM settings and defaults.

## Configuration Areas
- Pipeline stages and ownership
- Customer lifecycle, contacts, and commercial party profiles
- Ticket SLA hours by priority (`config/customer_tickets.php`)
- Sales targets (`sales_targets`) for forecast achievement
- Quotation, sales order, and invoice numbering
- Tax and payment defaults
- Price lists and discount rules
- Commercial automation and reminder cadence
- Customer portal billing / payment gateway
- Notification preferences
- Organization email (SMTP/provider, templates, webhooks)

Open these from **Administration → Configuration Hub**. The hub is a catalog; organization profile, HR catalogs, and commercial automation still use their existing routes. See [configuration-registry.md](../../product/configuration-registry.md).

CRM email guides: [configuration](../user-guide/email-configuration.md), [templates](../user-guide/email-templates.md), [webhooks](../user-guide/email-webhooks.md).

## Change Control
Apply changes in controlled windows and audit all updates.

# CRM User Guide - Opportunities

## Purpose
Manage pipeline opportunities from creation to closure.

## Who should use this feature
Sales reps, sales managers, and revenue operations.

## Prerequisites
- Pipeline stages configured
- Probability and amount fields available

## Step-by-step instructions
1. Create opportunity linked to lead/customer.
2. Set stage, expected close date, and value.
3. Update progress after each sales activity.
4. Close as won/lost with reason details.

## Expected result
Pipeline visibility improves forecasting and action planning.

## Best Practices
Update stage transitions immediately after key events.

## Common Mistakes
Skipping close reasons and outdated forecast values.

## FAQ
Cover stage definitions, ownership changes, and close rules.

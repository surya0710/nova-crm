# CRM User Guide - Reports

## Purpose
Use CRM reports for pipeline, revenue, and activity insights.

## Who should use this feature
Sales managers, operations analysts, and leadership users.

## Prerequisites
- Relevant reporting permissions
- Baseline data quality standards in place

## Step-by-step instructions
1. Select report type and date range.
2. Apply filters for owner, stage, or segment.
3. Review trends and export if required.
4. Share findings with stakeholders.

## Expected result
Teams make decisions using consistent CRM performance views.

## Best Practices
Use standardized filters for comparable period analysis.

## Common Mistakes
Comparing inconsistent scopes and stale data windows.

## FAQ
Cover filter logic, export format, and data refresh timing.

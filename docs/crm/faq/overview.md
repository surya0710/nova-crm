# CRM FAQ Overview

## Purpose
Frequently asked questions for CRM users and administrators.

## Common Topics
- Lead conversion rules
- Opportunity stage definitions
- Ticket workspace uses `customers.view` / `customers.update` (no extra ticket permissions)
- Sales executive REST calls need `api.access` in addition to entity permissions
- Quotation/invoice corrections
- Payment reconciliation
- Lifecycle stage does not move backward; each milestone is recorded once

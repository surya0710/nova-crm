# Getting Started

## Purpose
This guide introduces the Konnect Nex Knowledge Center and explains how documentation is organized and maintained.

## Audience
- End users
- Managers
- HR teams
- Administrators
- Developers
- API consumers

## How to Use the Knowledge Center
1. Open **Knowledge Center** from the app sidebar.
2. Choose a module from the left navigation.
3. Use search to find pages by title, heading, or keywords.
4. Use breadcrumbs and previous/next links to navigate.

## Documentation Principles
- Documentation is source controlled under `docs/`.
- Feature work is incomplete without documentation updates.
- User, admin, architecture, and API docs should evolve together.

## Versioning
- Documentation versions follow application releases.
- Release notes are tracked in `docs/release-notes/`.

# Churn Prevention

## Red flags
- Declining weekly active users
- Champion leaves company
- Unresolved P2s / repeated incidents
- Unpaid invoices
- Executive sponsor disengaged
- Competitor evaluation announced

## Response (48 hours)
- [ ] CS Lead notified
- [ ] Executive sponsor outreach scheduled
- [ ] Issue war-room if product-related
- [ ] Save plan with dates (training, fix, commercial options)
- [ ] AE informed for renewal strategy

Never discount silently to mask product gaps — fix or reset expectations.

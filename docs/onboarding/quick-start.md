# Quick Start Guide

Get productive in Konnect Nex in under an hour.

## 1. Sign in
1. Open your organization URL (provided at onboarding).
2. Sign in with the invite email.
3. Complete password setup if prompted.

## 2. Orient
| Area | Where |
|------|-------|
| Home / My Work | `/` |
| CRM | `/crm` |
| Projects | `/projects` |
| HR | `/hrms` |
| Marketing | `/marketing` |
| Analytics | `/analytics` |
| Administration | `/administration` |
| Help | Knowledge Center `/knowledge` · `⌘K` / `Ctrl+K` command palette |

## 3. First actions (by role)

**Sales:** Open CRM → create a Lead → convert path per your pipeline.  
**Project lead:** Open Projects → create Project → add Milestone and Task.  
**HR:** Open HRMS → confirm your employee profile → submit a leave request (if enabled).  
**Admin:** Administration → invite a colleague → assign role.

## 4. Next steps
- Complete your team’s onboarding training session
- Bookmark Knowledge Center module guides
- Contact support via the channel shared at go-live

# Onboarding Setup Checklist

- [ ] Import entities selected / Import Center scheduled
- [ ] Branding colors and footers set
- [ ] Organization email configured and verified
- [ ] Provider health reviewed
- [ ] Go-live checklist green on required items
- [ ] Customer handover (SOP-ONB-008)

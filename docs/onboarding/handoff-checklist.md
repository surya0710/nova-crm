# Sales → Implementation Handoff Checklist

**Complete within 2 business days of Closed Won.**

## Deal package
- [ ] Opportunity ID / deal name
- [ ] Signed Order Form / MSA attached
- [ ] Modules and seat counts
- [ ] Start date and go-live target
- [ ] Pricing / discount notes (for CS awareness, not re-negotiation)
- [ ] Implementation package included? (Y/N + hours)

## Customer contacts
- [ ] Economic buyer
- [ ] Customer Admin (day-to-day)
- [ ] Technical / IT contact
- [ ] Billing contact

## Discovery transfer
- [ ] Pain points and success metrics
- [ ] Current tools to replace / integrate
- [ ] Data import sources and volumes
- [ ] Known risks / objections
- [ ] Industry scenario notes (if demo was industry-specific)

## Logistics
- [ ] Implementation Lead assigned
- [ ] CS Owner assigned
- [ ] Kickoff meeting invited
- [ ] Internal Slack/Teams channel or ticket created

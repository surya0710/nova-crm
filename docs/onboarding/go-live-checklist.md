# Go-live Checklist

**Organization:** ________________  
**Go-live date:** ________________  
**Implementation Lead:** ________________

## Access & security
- [ ] Admins can log in
- [ ] MFA / password policy communicated (as applicable)
- [ ] Roles reviewed — no excessive org-wide admin grants
- [ ] Platform vs tenant sessions understood (no mixing)

## Organization foundation
- [ ] Branches, departments, holiday calendar, leave types configured
- [ ] Branding applied
- [ ] Subscription / plan matches Order Form

## Module smoke (scoped)
- [ ] CRM: create lead → opportunity → quotation path works
- [ ] Projects: create project → milestone → task works
- [ ] HRMS: employee profile + leave request path works (if licensed)
- [ ] Marketing: campaign list loads (if licensed)
- [ ] Analytics: executive / module dashboards load (if licensed)
- [ ] Administration: user invite works

## Data & integrations
- [ ] Import counts reconciled
- [ ] Integrations healthy or deferred with owner
- [ ] Sample reports reviewed with Customer Admin

## Support readiness
- [ ] Support channel and SLA shared
- [ ] Knowledge Center bookmarked
- [ ] Escalation contacts listed

## Business readiness
- [ ] UAT sign-off received
- [ ] Training sessions completed or scheduled
- [ ] Internal champions named
- [ ] Hypercare window agreed (typically 2 weeks)

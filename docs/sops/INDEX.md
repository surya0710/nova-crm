## Naming convention

| Prefix | Department |
|--------|------------|
| SOP-SAL | Sales |
| SOP-ONB | Onboarding |
| SOP-IMP | Implementation (reserved) |
| SOP-ADM | Administration |
| SOP-DEP | Deployment |
| SOP-SUP | Support |
| SOP-MNT | Maintenance |
| SOP-CS | Customer Success |
| SOP-SEC | Security |
| SOP-BIL | Billing |
| SOP-MIG | Migrations (reserved) |
| SOP-MON | Monitoring |
| SOP-DR | Disaster Recovery |
| SOP-REL | Release Management |
| SOP-OFF | Offboarding |

Format: `SOP-<DEPT>-<NNN>` with zero-padded sequence. **IDs never change once assigned.**

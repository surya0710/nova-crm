## Purpose
Deliver a repeatable onboarding lifecycle from organization provisioning through go-live validation.

## Roles
| Role | Responsibility |
|------|----------------|
| Implementation Lead | Plan, configure, validate, go-live |
| Platform Operator | Org provisioning, plan/subscription |
| Customer Admin | Branding, users, day-to-day config |
| Customer Success | Training schedule and adoption |

## Prerequisites
- Signed Order Form / Closed Won deal
- Handoff package complete
- Access to Platform console (`/platform`)

Detailed checklists: [Onboarding Playbook](../onboarding/playbook.md) · [Go-live Checklist](../onboarding/go-live-checklist.md)

## Procedure overview
| Step | Owner | Artifact |
|------|-------|----------|
| 1. Organization provisioning | Platform Operator | Org record active |
| 2. Subscription assignment | Platform Operator | Plan / seats match Order Form |
| 3. Domain configuration | Implementation | Custom domain / APP_URL notes if applicable |
| 4. Branding | Customer Admin | Logo, colors, company profile |
| 5. User creation | Implementation + Admin | Initial admin + key users |
| 6. Roles & permissions | Implementation | Role map signed off |
| 7. Branch setup | Implementation | Branches match org structure |
| 8. Departments | Implementation | Department tree |
| 9. Holiday calendar | Implementation | Region calendars |
| 10. Leave types | Implementation | Leave policy mapped |
| 11. CRM configuration | Implementation | Pipelines, sources, products |
| 12. Project configuration | Implementation | Types, statuses, defaults |
| 13. HRMS configuration | Implementation | Shifts, leave, payroll basics |
| 14. Provider integrations | Implementation | Marketing / ads / webhooks as scoped |
| 15. Data import | Implementation | Validated import logs |
| 16. Validation | Implementation + Customer | UAT sign-off |
| 17. Go-live | Implementation + CS | Go-live checklist complete |

## Exit criteria
- [ ] Customer Admin can log in and perform core workflows
- [ ] Go-live checklist signed
- [ ] Support channel and SLA communicated
- [ ] CS welcome / training schedule booked

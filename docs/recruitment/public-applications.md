# Public Applications

## Purpose
Candidates can apply through the careers portal with or without an account depending on portal settings.

## Submission Types
- `portal_guest` — one-time guest application with resume upload
- `portal_account` — authenticated candidate application
- `internal` — recruiter-created application in HRMS

## Business Rules
- Applications accepted only for published, non-closed openings
- One active application per candidate per opening
- Draft applications can be submitted later by logged-in candidates
- Withdrawn applications cannot be edited
- Profile snapshots preserve historical application data

## Events
- `ApplicationSubmitted`
- `JobApplied`
- `ApplicationWithdrawn`

## Notifications
- Candidates receive in-portal notifications for submissions
- Recruiters receive CRM notifications for new applications and withdrawals

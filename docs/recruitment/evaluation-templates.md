# Evaluation Templates

## Purpose
Define reusable interview scorecards with weighted sections and structured questions.

## Template Structure
```
EvaluationTemplate
├── EvaluationSection (title, weight, order)
│   └── EvaluationQuestion (type, required, weight, order)
```

## Question Types
- Rating (1–5)
- Rating (1–10)
- Yes/No
- Text
- Multi-line comments

## Business Rules
- Templates can be scoped to a department and/or designation
- Templates in use by interview rounds or evaluations cannot be deleted
- Required questions must be answered when submitting an evaluation

## Usage
1. Create a template from **Recruitment → Interview Templates**.
2. Assign the template when scheduling an interview round.
3. Interviewers submit evaluations using the template scorecard.

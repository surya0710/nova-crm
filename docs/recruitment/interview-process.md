# Interview Process

## Purpose
Describe the end-to-end interview workflow from application to hiring recommendation.

## Default Pipeline Stages
1. Applied
2. Screening
3. Technical Interview
4. Manager Interview
5. HR Interview
6. Final Review
7. Offer
8. Hired / Rejected / Withdrawn

## Interview Round Lifecycle
```
Draft → Scheduled → Completed
                 ↘ Cancelled / No Show
```

## Workflow
1. Recruiter schedules an interview round for an application.
2. One or more interviewers are assigned (internal employees or external contacts).
3. Interviewers submit structured evaluations with recommendations.
4. When all evaluations are submitted, the round can be marked completed.
5. Workflow events fire for scheduling, completion, evaluation submission, and hiring recommendations.

## Recommendations
- Strong Hire
- Hire
- Hold
- Reject

## Out of Scope
Calendar integrations, video meeting links, candidate self-scheduling, and employee onboarding are not part of this phase.

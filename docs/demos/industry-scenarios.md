# Industry Demo Scenarios

Use the same Nova Enterprises demo data; change **narrative and path emphasis**. Duration: 25–35 minutes each.

## 1. Immigration Consultancy
**Pain:** High lead volume, case-like delivery, document-heavy HR.  
**Path:** Marketing/leads → CRM opportunities (visa packages as products) → Projects as case files → HRMS documents/compliance touch → Analytics conversion funnel.  
**Talk track:** “From inquiry to case completion with one client record.”

## 2. Software Company
**Pain:** Pipeline + delivery + engineering capacity.  
**Path:** CRM opportunities → Projects/portfolios → resource workload → sprint-like tasks → Analytics project + sales.  
**Talk track:** “Connect closed-won work to delivery capacity before you overcommit.”

## 3. Healthcare
**Pain:** Multi-location staff, attendance, credential documents, vendor CRM.  
**Path:** Branches → employees/shifts/attendance → documents/assets → CRM for institutional customers → compliance-friendly admin.  
**Talk track:** “Workforce reliability and institutional relationships in one place.”

## 4. Real Estate
**Pain:** Property leads, site projects, broker/partner activity.  
**Path:** Lead sources → opportunities with high ticket values → quotations → project milestones (handovers) → marketing campaigns.  
**Talk track:** “Track every inquiry through booking and handover.”

## 5. Consulting Services
**Pain:** Utilization, proposals, multi-project delivery, hiring.  
**Path:** Opportunities/quotations → projects + resource allocations → recruitment for open roles → analytics utilization/revenue.  
**Talk track:** “Win work, staff it, and see margin risk early.”

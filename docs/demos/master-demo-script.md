# Master Demo Script

**Duration:** 45–60 minutes  
**Org:** Nova Enterprises  
**Login:** `demo@novacrm.test`

## Timing guide

| Section | Minutes |
|---------|---------|
| Company introduction | 3 |
| Dashboard / Home | 4 |
| CRM | 10 |
| Projects | 8 |
| HRMS | 8 |
| Marketing | 4 |
| Analytics | 5 |
| Organization administration | 4 |
| Platform administration (optional / internal) | 3 |
| AI features | 3 |
| Closing | 3 |

## 1. Company introduction
- NovaCRM is a multi-tenant SaaS suite: CRM, Projects (EPM), HRMS/Recruitment, Marketing attribution, Analytics.
- Single organization context with role-based workspaces.
- Today’s story: Nova Enterprises running growth + delivery + people on one platform.

## 2. Dashboard
- Open Home / workspace home widgets.
- Call out quick actions and command palette (`⌘K` / `Ctrl+K`).
- Show how each workspace home surfaces KPIs.

## 3. CRM
- Leads list → open a hot lead → discuss sources/priority.
- Pipeline / opportunities → stage and amount.
- Quotation → invoice → payment (revenue lifecycle).
- Emphasize customer 360 and activity history.

## 4. Projects
- Projects home → open an active project.
- Milestones and tasks; membership / resources.
- Mention portfolios/programs/risks if audience is PMO.

## 5. HRMS
- Employees directory → manager hierarchy.
- Attendance / leave snapshot.
- Recruitment pipeline highlight (opening → candidate).
- Touch payroll/assets/documents lightly unless HR-heavy audience.

## 6. Marketing
- Marketing home: campaigns, CPL, channel performance.
- Tie campaign → lead → opportunity narrative.

## 7. Analytics
- Analytics home: executive + module analytics.
- KPI library / AI insights banner if enabled.
- “One truth” across sales, delivery, and people.

## 8. Organization administration
- Branding, users/roles, modules.
- Stress least-privilege roles.

## 9. Platform administration (partner / internal demos only)
- `/platform` isolation from tenant sessions.
- Org provisioning + monitoring widgets.

## 10. AI features
- Show available AI insights / assistants as licensed.
- Set expectation: assistive, human-approved actions.

## 11. Closing
- Recap modules mapped to buyer pain.
- Propose pilot scope + success metrics.
- Next step: proposal + sandbox / pilot timeline.
- Leave leave-behind: one-pager + security overview links.

# User Guide — Platform Updates (11.8.1)

## Finding configuration

Branches, shifts, leave types, holidays, and working days moved to **Organization Settings**.

HR and Self-Service menus focus on day-to-day work (employees, attendance, leave applications, payroll, recruitment).

## Payslips

Payslip filters now use month and year pickers plus **Current Month** / **Previous Month** shortcuts.

## Self-service without an employee profile

If your login is not linked to an employee record, you will see a clear empty state asking HR to link your profile — not an access denied error.

## Recruitment interviews

When scheduling interviews, recruiters can choose Google Meet, Microsoft Teams, Zoom, Jitsi Meet, or a custom meeting URL. Invitation messages include the join link.
